Init

  • Object
    • state(starting mood)
      string,
      default: "idle"
    • starting message
      string,
      default: ""
    • parent (required)
      string,

this same function can be called as "birth" & "create"

Usage:

import askiimon from "askiimon-web";

const mon = askiimon.init({
    mood: "ohh!",
    message: "",
    parent: "parent" // just pass in the parent element's id
});
