setIntervals

  • boolean (required)
    boolean,
    default: true
  • interval_timing (required)
    number,
    default: 2000

Usage:

import askiimon from "askiimon-web";

const mon = askiimon.init({
    mood: "ohh!",
    message: "",
    parent: "parent" // just pass in the parent element's id
});

mon.setIntervals(true, 5000); // can be used to add/remove intervals between setMessage, & setMood
//           the time is measured in miliseconds
